# 🩺 Medical Chatbot LLM (RAG-based)

An AI-powered Medical Chatbot built using Flask, LangChain, Pinecone, HuggingFace Embeddings, and LLMs.

## 🚀 Features
- AI-powered medical question answering
- Retrieval-Augmented Generation (RAG)
- LangChain + Pinecone integration
- Beautiful custom chatbot UI
- Real-time chat interface
- Dynamic recent chat sidebar
- Medical disclaimer support

## 🛠️ Tech Stack
- Python
- Flask
- LangChain
- Pinecone
- HuggingFace Embeddings
- HTML/CSS/JavaScript

2. Install dependencies
3. pip install -r requirements.txt
4. Run application
5. python app.py
